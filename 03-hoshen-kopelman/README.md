# Практическая работа 3: Алгоритм Хошена-Копельмана и поиск перколяционного кластера

Параметры, которые не указаны при запуске, программа спрашивает сама. Результаты сохраняются в `out/` внутри папки задания.

## Задание 1. Алгоритм Хошена-Копельмана → [`task1`](task1)

Решётка читается из файла (`-i example.txt` — матрица 6 x 6 из задания) или генерируется по L и p, как в работе 1.
Кластеры размечаются за один проход по строкам с таблицей склеек меток, вторым проходом метки нумеруются подряд с 1.
Разметка сверяется с обходом в ширину. На выходе `out/clusters.txt` с исходной решёткой, матрицей меток
и распределением кластеров по размерам, по желанию картинка с кластерами разного цвета.

Проверял на таких данных:

| решётка                   | кластеров | результат                                           |
|---------------------------|-----------|-----------------------------------------------------|
| `example.txt`             | 4         | размеры 16, 2, 1, 1 — совпадает с разметкой вручную |
| L = 8, p = 0.6, seed 3    | 4         | совпадает с обходом в ширину                        |
| L = 2000, p = 0.6, seed 2 | 101837    | совпадает с обходом в ширину, разметка за 0.1 с     |

## Задание 2. Поиск перколяционного кластера → [`task2`](task2)

Читает матрицу меток из `../task1/out/clusters.txt`. Перколяционный кластер — тот, что касается и верхнего, и нижнего
края решётки. На выходе `out/percolation.txt`: `1` и номер и размер кластера или `0`, если такого нет.

Проверял на таких данных:

| решётка                    | результат                                                                                  |
|----------------------------|--------------------------------------------------------------------------------------------|
| `example.txt`              | 1, кластер 1 размером 16                                                                   |
| L = 8, p = 0.6, seed 3     | 0: ни один кластер не касается обоих краёв                                                 |
| 3 x 3, столбцы `1 0 1`     | 1, сразу два кластера размером 3: на маленькой решётке перколяционных может быть несколько |
| L = 1000, p = 0.55, seed 1 | 0: ниже порога p_c ≈ 0.5927                                                                |
| L = 1000, p = 0.63, seed 1 | 1, кластер размером 577583, это 92% занятых узлов                                          |
